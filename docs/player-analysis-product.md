# 短线王 · 选手分析｜产品需求文档

**V1.0 · 2026-11-22**　配套阅读：[技术设计、接入核对与验收](player-analysis-technical.md)

**采集比赛。** 在一级「选手分析」粘贴已报名的比赛链接，点「登录并采集」。短线王打开本机浏览器，用户在淘股吧完成登录和安全验证。比赛页显示本人账号后，程序核对同场参赛记录，直接在这个窗口读取全场累计榜、展开可见持仓、逐页核对并发布当天快照。页面显示采集进度、人数、日期和版本。后续可点击「立即同步」，Windows 用户也可启用盘后同步。「用默认浏览器查看」按用户的系统设置打开比赛网址。

**本场实测。** 普通登录账号可以看 2026 官方年赛的排名、收益和仓位。11 月 20 日的个别选手战绩明细打星，11 月 11 日同一选手可展开持仓和卖出。官网榜单中的「今交易」和「仓位」分别表达当天交易及收盘仓位。榜单披露了收益的记录可参加收益统计，主动报单人数另计。已用两页浏览器样例验证全场读取流程，真实已报名账号的近期明细和无人值守更新尚未验收。[年赛榜单](https://www.tgb.cn/spmatch/matchAll?tid=2nPcAoCrpCL)

**未报名也能读榜。** 粘贴比赛链接，点「登录并采集」。首次连接未核验到同场报名时，短线王读取官网当前窗口可见的全场榜单，在「官网可见榜单」按交易日展示排名、收益、仓位及可见持仓。被遮挡或缺报的字段保留缺失，只有官网明确披露空仓才标为空仓。参赛账号的盘后同步和报单详情继续核验同场报名。

**手工补录上千人比赛。** 在已核对的比赛中点击“打开本场官网榜单”，在官网选择同一赛组和交易日，逐页复制带表头的榜单。每粘贴一页可点“暂存并添加下一页”，最后一次预览、一次确认。界面显示去重后的选手人数。重叠页中同一选手的数据有变化时，请核对官网后重新整理。只有核齐该赛组累计收益榜后才勾选完整。单页、部分榜单也可以保存，首尾组比较会提示覆盖不足。

**如何解读遮挡和首日记录。** 一行报单有部分股票打星号时，选手档案仍列出可见证券和已披露收益；共同持仓和新增、退出统计只计入完整可比报单。年赛首日报初始资金时可以没有收益和名次，界面保留缺失状态。修订已导入的一天时，预览会列出名单或可读持仓覆盖下降的情况。[年赛章程](https://m.tgb.cn/a/2nPcAoCrpCL)

## 1. 产品目标

**同场录入与报单原图。** 用户可在「核验参赛记录」同时填写本人主页与已报名的比赛详情链接。核验成功后定位该场，读取近期报单时使用本人参赛账号。普通账号研究样本中的打星不代表参赛用户也被遮挡。

**使用已经登录的默认浏览器。** 在短线王核验本人参赛记录后，填写本场链接，在「从官网读取全场榜单」下载并安装本场读取书签。在默认浏览器的官网比赛页点书签，选好对应交易日后，短线王的读取器使用该标签页已显示的数据。读取完成点「送回短线王」，在工作台核对日期、人数，点「保存并查看分析」。首次使用过旧版读取书签的用户需要重新下载。后台定时任务则使用短线王管理的持久浏览器会话，每次核验登录和同场资格。

**报单原图。** 选手提交的截图是当天报单的凭证，和同日仓位、持仓一起展示入口。正常分析直接使用赛方披露的结构化数据。可使用已连接的比赛账号打开对应选手和日期的官网战绩页，查看官网提供的原图，榜单导入不会同时下载图片。发现填写差异时才展开「核对并记录更正」，对照可读原图，选择需修正的字段。截屏不全时记录为部分持仓。本地更正形成新版本，官网收益、名次和原版本仍可核对。

为参加淘股吧实盘比赛的用户提供每日盘后复盘。在一场上千人的赛事里，用户打开一页就能判断选手整体盈亏与仓位，找到领先组选手集中持有的股票，再点回具体选手核实。值得继续观察的选手可以关注，相关股票可以带着当天日期进入 K 线复盘。

「选手分析」是短线王左侧独立一级入口，与「复盘」「研究」并列。一个视图始终对应**一场比赛、一个排名范围、一个交易日和一个数据版本**。页面上的“全场”指当前排名范围内的全部选手；切到独立赛组时列名改为“全组”。这些数字描述参赛样本。

## 2. 每日使用路径

1. **首次添加比赛。** 用户在淘股吧完成报名，在短线王选择或粘贴赛事链接。确认名称、可选赛组、可读日期、字段和数据取得方式。可用数据源通过验证后，保存比赛并获取首个快照。遇到权限不足时说明受限项目；已有可用文件时可走导入预览。
2. **收盘后打开。** 默认恢复上次赛事、赛组，显示最近有数据的交易日、更新时间及报单进度。历史日期由用户明确选择；查看旧日期时遇到新数据，保留当前日期。
3. **先看全场。** 全场、前 20、后 20 并排展示。点击任一格可看计算口径、有效人数和对应选手。切到“收盘仓位”“当日收益”分布，查看中位数背后的分化。
4. **再看股票。** 切到“领先组偏好”或“净增持有人数”，选一只股票，查看同日持有人和跨日新增、继续、退出的人。可打开截至当日的 K 线或建立观察卡草稿。
5. **留下跟踪对象。** 在选手详情关注一人，次日在“我关注的选手”继续看其最新可见报单。回到总览时，“自选股收盘速览”直接列出与自己当前自选股有关的事实。

## 3. 页面安排

| 位置 | 用户首先看到 | 下一步操作 |
|---|---|---|
| 顶栏 | 比赛、赛组、交易日、更新时刻、数据状态 | 换赛、换日、刷新或查看导入记录 |
| 总览 | 报单进度、三组对照、仓位与盈亏两张分布图 | 调前后 N、切分组依据、点人数看成员 |
| 股票 | 共同持仓、领先组偏好、人数变化；股票详情内展示近 5 个交易日 | 查看持有人、K 线、观察草稿 |
| 选手 | 当前榜单、排名迁移、持续领先、我关注的选手 | 查找选手、关注、打开个人时间轴 |
| 总览内的自选股速览 | 最多三条带人数的规则摘要及“查看全部匹配” | 点击原始股票行，沿用原日期、样本和版本 |

桌面端在列表右侧展开详情；窄屏进入独立详情，返回时恢复排序、筛选和滚动位置。所有分布图同时提供人数和可读标签，颜色只作为辅助。

## 4. 首版交付清单

| 编号 | 功能 | 可验收的行为 |
|---|---|---|
| A1 | 我的比赛、赛组与历史日 | 记住最近选择。独立赛组各自排名，历史回看沿用当日成员，退赛前的记录可查。 |
| A2 | 报单与数据覆盖 | 并列显示应报、当日主动报单、平台沿用、完整持仓可读人数。未知分母显示原因；同步中显示进度和最近已发布版本。 |
| A3 | 全场与前后 N 名 | 默认前后各 20，支持人数或百分比。表内给出盈利占比、日收益中位数、总仓位中位数、总仓位上升占比；逐格可查样本。 |
| A4 | 昨日分组／今日榜单 | 默认固定上一交易日累计收益榜成员，观察这批人今日表现。切到今日榜单可查看今日领先者持仓。首日提示仅今日分组可用。 |
| A5 | 共同持仓与变化 | 展示持有数和持有率。连续两日可比时展示新增、继续、退出、净增；今天已无人持有的股票也能出现在退出列表。 |
| A6 | 选手档案 | 日期对齐当日及累计收益、名次、总仓位、股票、报单状态。历史断点留白，允许回到该日原始记录依据。 |
| A7 | 个股反查与复盘 | 从一只股票反查所有有效持有人，按组选人。在 K 线定位当天，观察草稿保留股票、日期、指标来源，用户确认才保存。 |
| E1 | 领先组选股偏好与变化（B2＋B3） | 同表对比领先组与全场持有率和百分点差，紧邻显示昨日到今日的人员变化。股票详情展示近 5 日轨迹与每日可比人数。 |
| E2 | 全场仓位与盈亏分布（B1＋B7） | 全场、领先、落后三组使用相同区间，展示各区间人数、组内占比和缺失数。点击柱子看该区间的选手。 |
| E3 | 持续领先与关注（B5＋B6＋B10） | 标识新晋、留榜、跌出，展示连续在榜天数、近 20 日进前 10% 天数、同期最大回撤和有效天数。关注后随排名变化保留。 |
| E4 | 自选股收盘速览（B9＋C4） | 读取短线王当前自选股，与当前赛事股票表匹配。规则摘要可点击核对，无自选、无交集、数据缺失分别提示。 |

## 5. 会改变用户判断的统计规则

**谁可以进入前后组。** 使用选定日期、选定赛组的官方累计收益榜。名额在排名日确定，今天缺报也保留名额。人数过少时提示实际可选范围。前后组保持互斥；百分比向上取整，并列沿用官方顺序。无法确定边界顺序时标明并列待定。只取得部分榜单时提示覆盖范围，缺少尾部数据时暂停后组对照。

**仓位上升和盈利如何读。** 盈利人数占比的分母是日收益可用人数，零收益计入分母。仓位上升指连续两日总仓位比例变高，行情波动也能造成变化。界面用“仓位上升”“新增持有”等收盘事实。平台明确沿用旧报单的记录独立计数，行为统计只使用可确认的新报单。

**偏好与变化怎么区分。** 示例：一只股票有 6/18 名领先选手持有，全场有 120/1,500 人持有，偏好差为 **+25.3 个百分点**。若 6 人中两人在昨天已有该股、今天才进入前 20，这两人贡献今日偏好，但其股票归为“继续持有”。同一表格同时展示持有率分母和连续可比人数。遮挡某只股票时，整条持仓明细从完整样本中剔除，明确空仓则计入完整样本。

**持续领先怎么读。** “连续在榜”按当前选定前 N；“近 20 日进前 10%”固定为赛组累计收益榜前十分之一。只有 6 个交易日资料时显示“已观察 6 日，4 日进前 10%”。完整 20 日覆盖的选手才参加持续领先比较。最大回撤依据所示窗口内的比赛净值峰谷计算，与进榜天数分列。

**历史日与个人自选。** 历史页标注“按当前自选股匹配”，防止把今天的自选误读为历史自选。观察卡的复盘交易日与未来计划复核日分开填写。补报或修订形成新数据版本，之前保存的观察依据仍可定位原版本。

## 6. 数据接入与页面状态

淘股吧公开赛事页列有赛事、选手人数和累计平均收益。2017 年官方规则说明记载过同场选手互看持仓、请假沿用、赛后修订等机制。首版接入前需用当前参赛账号核对一场比赛两个连续交易日，确认平台支持的读取或导出方式、授权使用范围、实际字段和更新时间。[公开赛事列表](https://www.tgb.cn/spmatch/index/) · [APP 实盘比赛规则说明](https://m.tgb.cn/a/1ykBDNwqjH8)

| 遇到的情况 | 用户看到的结果 |
|---|---|
| 有榜单及收益，仓位或股票明细受限 | 榜单、收益照常显示，仓位或持仓区域标注缺失原因及数据日期。 |
| 已提交报单，但持股遮挡、停牌沿用或请假 | 分开显示状态，可看已知事实；各指标展开后可核对纳入、排除人数。 |
| 晚到、补报、刷新中断 | 显示最近可用版本、覆盖人数和刷新状态。新版本发布时给出时间，允许刷新查看。 |
| 全场已报单但今天都空仓 | 完整样本人数可见，持仓数为零；只有样本不可用时才显示“暂无可读持仓”。 |
| 账号失去赛事权限 | 停止更新，依照原授权范围决定可读历史，提示恢复授权或导入可用数据。 |

## 7. 验收与发布边界

- **产品验收路径。** 用两个连续交易日的同场数据完成“总览 → 偏好榜 → 股票 → 持有人 → 关注 → 次日复查”，以及“自选股摘要 → 原表 → 历史 K 线 → 观察草稿”。每一步可返回原视图。
- **数值验收。** 人工抽查前后组及全场的有效人数；选一只股票逐人复算偏好、持有人净增和退出。另用有明确期望值的 20 日样本验算持续领先和回撤，详见技术文档。
- **范围验收。** A1–A7、E1–E4 均属首版。自动更新用真实同场参赛账号验收，从官网正常登录、读取最近交易日全场榜单和可见持仓，到写入本地分析及次日同步，逐项核对记录与原图。板块轮动、跨赛合榜、主动提醒、成交归因、历史信号回测留待后续评估。
